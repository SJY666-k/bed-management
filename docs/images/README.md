# 界面截图目录

根目录 `README.md` 顶部「📸 界面预览」一节引用的图片都放在这个目录。

## 现在里面是什么

仓库里现在放的是 **3 张占位图（`.svg`）**，图上直接写明了本该显示什么内容。
这样做的目的：README 在 GitHub 上打开时**不会出现"裂图"**，同时提醒你后面补真实截图。

| 文件 | 对应页面 | 怎么截 |
| --- | --- | --- |
| `01-bed-map.svg` | 床位示意图 | 前端左侧菜单「床位示意图」，选一层，能看到 101~106 房间和绿/蓝/橙三色床位 |
| `02-bed-manage.svg` | 床位管理列表 | 前端左侧菜单「床位管理」，页签「正在使用」，能同时看到查询条件 + 表格 + 操作按钮 |
| `03-api-test.svg` | 接口自测结果 | 终端执行 `powershell -ExecutionPolicy Bypass -File verify\api-test.ps1`，截最后"32 项全部通过"那几行 |

> 前端启动方式见根目录 README 的「🚀 只想赶紧跑起来？」或「三、怎么跑起来」。

## 怎么替换成真实截图（两步）

**第 1 步：截图并保存**

- Windows 截图快捷键：`Win + Shift + S`（框选后会自动进剪贴板，粘到画图/微信里另存为 PNG 即可）
- 文件名建议与占位图一致，扩展名用 `.png`：

```
docs/images/01-bed-map.png
docs/images/02-bed-manage.png
docs/images/03-api-test.png
```

**第 2 步：改 README 里的引用，然后提交**

打开根目录 `README.md`，在「📸 界面预览」一节把 `.svg` 改成 `.png`：

```markdown
| ![床位示意图](docs/images/01-bed-map.png) | ![床位管理列表](docs/images/02-bed-manage.png) |

![接口自测 32 项全部通过](docs/images/03-api-test.png)
```

```bash
git add -A
git commit -m "docs: 补充界面截图"
git push
```

替换完成后，可以顺手把 3 个 `.svg` 占位图删掉（`git rm docs/images/*.svg`），保持目录干净。

## 小贴士

1. **宽度**：图片宽度建议不超过 1200px。太宽会把 README 的表格撑破，看起来像没排版；整窗截图后按 60%~70% 缩放比较合适。
2. **体积**：单张图尽量别超过 1MB（GitHub 单文件上限 100MB，但仓库越大克隆越慢，而且图片一旦提交就永久留在 Git 历史里）。
3. **隐私**：截图里不要露出真实数据库密码、真实客户姓名等敏感信息。本项目用的是演示数据，正常情况下不会踩坑。
4. **表格里放图**：GitHub 会把表格单元格里的图片等比例放大到列宽，两列布局（两张图并排）比一张张大图更省空间。
